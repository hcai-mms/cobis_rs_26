# Feedback Loop Simulation Framework for the "Cognitive Biases in Recommender Systems" tutorial @ RecSys'26

See the notebook `SimRunner.ipynb` to get started;
(Python 3.11.14 recommended)

This repo is based on the paper "Oh, Behave! Country Representation Dynamics Created by Feedback Loops in Music Recommender Systems" by [Oleg Lesota](mailto:oleg.lesota@jku.at), [Jonas Geiger](mailto:jonasgeiger@outlook.de), [Max Walder](mailto:max@gstat.eu), Dominik Kowald and Markus Schedl published at RecSys 2024.

Paper: [https://dl.acm.org/doi/10.1145/3640457.3688187](https://dl.acm.org/doi/10.1145/3640457.3688187)
